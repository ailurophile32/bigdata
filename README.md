# 反射率光谱对比分析工具

这是一个用于显示和分析光谱反射率数据的Python应用程序。该应用程序可以读取特定格式的CSV文件，并在同一张图表中以多折线图的方式可视化波长和反射率数据，用于比较不同样本之间的差异性。

## 功能特点

- 浏览并自动加载包含反射率数据的CSV文件
- 在同一图表中显示所有光谱数据进行比较分析
- 可调整波长范围进行特定区间的对比
- 自动为不同文件的数据分配不同颜色
- 交互式图表工具(放大、缩小、平移等)
- 支持从多个子文件夹中读取数据
- 自动处理NaN值和数据异常
- 优化的图例显示，便于识别每条曲线

## 系统要求

- Python 3.12 或更高版本
- PyQt6
- Matplotlib
- NumPy
- Pandas

## 安装

1. 确保已安装Python 3.12
2. 安装所需依赖库:

```bash
pip install PyQt6 matplotlib numpy pandas
```

## 使用方法

1. 运行应用程序:

```bash
python spectra_viewer.py
```

2. 点击"加载数据文件夹"按钮，选择包含反射率CSV文件的根文件夹
3. 应用程序将自动读取所有CSV文件并在同一张图表中显示
4. 使用波长范围控制可以聚焦于特定波长区间的数据对比
5. 使用图表工具栏进行缩放、保存图像等操作
6. 如需刷新显示，点击"刷新显示"按钮

## 数据文件格式

应用程序支持以下格式的CSV文件:

- 文件开头包含元数据部分
- 数据部分开始于"---------------BEGIN--------------------"标记行后的两行
- 或者数据部分开始于包含"Wavelength(nm)"和"Reflectance(%)"的标题行后
- 数据行格式为: `波长值,反射率值`
- 支持NaN值
